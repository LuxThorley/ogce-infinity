# v4.1 release gates — not yet satisfied

- Custom AAA renderer parity, full PBR GPU shading, advanced GI, post-processing and GPU QA.
- Full glTF/GLB import (geometry, textures, animation, skinning, morph targets, extensions).
- Complete editor docking UI, transform gizmos, prefab workflows, asset dialogs and autosave.
- Dedicated multiplayer deployment, encrypted transport, identity, abuse controls and load/chaos tests.
- Production authentication, billing, licensing, compliance and support operations.
- Signed/notarized installers, secure automatic updates, rollback and key custody.
- Real Windows/Linux/macOS test matrix and supported hardware/driver matrix.
- GPU performance budgets, fuzzing, penetration tests, certification and long-duration soak tests.

v4.1 contains useful engineering foundations and prototypes for these areas. It is not a
production-certified AAA engine or commercial SaaS/game platform.
